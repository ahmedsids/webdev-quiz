# Expense Tracker

A small React app to track income and expenses.

**Features:** add transactions with validation (Formik + Yup), delete them, filter by income/expense,
live balance summary, data saved in the browser (localStorage), responsive and dark mode friendly.

**Tech:** React, Vite, Formik, Yup

## Run
```
npm install
npm run dev
```
Open http://localhost:5173

## Deploy
Push to GitHub, then import the repo on vercel.com.
